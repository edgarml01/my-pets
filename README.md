# MyPets - E-commerce para Productos de Mascotas

MyPets es una plataforma de comercio electrónico diseñada para ofrecer una experiencia de compra única para los amantes de las mascotas. Este proyecto permite a los usuarios explorar y adquirir productos para sus mascotas, como alimentos, juguetes, accesorios y más.

## Características Principales

- **Catálogo de Productos**: Navega por una amplia variedad de productos organizados por categorías como perros, gatos, aves y peces.
- **Carrito de Compras**: Agrega productos al carrito y gestiona las cantidades antes de realizar la compra.
- **Gestión de Usuarios**: Registro e inicio de sesión para usuarios, con roles diferenciados (administrador y cliente).
- **Panel de Administración**: Los administradores pueden gestionar productos, categorías, usuarios y pedidos.
- **Productos Relacionados**: Visualiza productos relacionados en las páginas de detalle de cada producto.
- **Diseño Responsivo**: Interfaz optimizada para dispositivos móviles y de escritorio.

## Estructura del Proyecto

El proyecto está organizado en las siguientes carpetas principales:

- **Assets/**: Contiene los archivos estáticos como CSS, JavaScript e imágenes.
- **Config/**: Configuración del proyecto.
- **Controllers/**: Controladores que manejan la lógica de negocio.
- **Helpers/**: Funciones auxiliares para el proyecto.
- **Libraries/**: Clases base y librerías personalizadas.
- **Models/**: Modelos para interactuar con la base de datos.
- **Views/**: Vistas que renderizan la interfaz de usuario.
- **tienda_mascotas2.sql**: Archivo SQL para la estructura de la base de datos.

## Tecnologías Utilizadas

- **Backend**: PHP (con un enfoque MVC).
- **Frontend**: HTML, CSS, JavaScript (incluyendo librerías como jQuery y Bootstrap).
- **Base de Datos**: MySQL.

## Instalación

1. Clona este repositorio en tu máquina local.
2. Configura el archivo `Config/Config.php` con los datos de tu servidor y base de datos.
3. Importa el archivo `tienda_mascotas2.sql` en tu servidor MySQL.
4. Asegúrate de que el servidor web tenga acceso a las carpetas necesarias.
5. Accede al proyecto desde tu navegador.
